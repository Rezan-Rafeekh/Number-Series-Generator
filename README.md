# Number-Series-Generator using JavaScript

## 📄 Description

A JavaScript-based number series generator that produces different numerical sequences based on user input. The application allows users to generate the **Fibonacci series**, **first n even numbers**, or **first n odd numbers** through interactive buttons, with results displayed dynamically on the web page.

---

## ⚙️ Features

* Accepts a numeric input from the user
* Generates multiple number series using button controls:

  * Fibonacci series
  * First n even numbers
  * First n odd numbers
* Displays the generated series dynamically
* Ensures clear and interactive user experience

---

## 🛠️ Technologies Used

* HTML5
* JavaScript (ES6)

---

## ▶️ How to Run

1. Open the project folder in **Visual Studio Code**
2. Open `index.html` in a web browser or using **Live Server**
3. Enter a number when prompted and click the desired series button

---

## 🎯 Learning Outcomes

* Implementing loops and iterative logic
* Generating mathematical number series
* Handling button-based events in JavaScript
* Displaying dynamic output using DOM manipulation
